    How it works

    1. Hourly ingest. A GitHub Actions job reads 10 public RSS feeds. Stories are de-duplicated by canonical link, and one broken feed never stops the run.
    2. Sentiment. A RoBERTa transformer (cardiffnlp/twitter-roberta-base-sentiment-latest) gives each headline negative, neutral and positive probabilities. Tone is positive minus negative. Each article is scored once.
    3. Meaning. A sentence-transformer (all-MiniLM-L6-v2) turns headlines into 384-dimensional embeddings.
    4. Stories. HDBSCAN finds dense groups of headlines without being told how many there are. Class-based TF-IDF names each group, BERTopic-style.
    5. Serve. This page rebuilds hourly on GitHub Pages. A FastAPI Docker image scores any text and matches it to today's stories.
    Headlines and links belong to their publishers; only titles and RSS summaries are processed. Sentiment models make mistakes, especially with sarcasm and mixed news.
